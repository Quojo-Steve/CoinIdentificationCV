# CoinIdentificationCV

Classical computer vision pipeline that segments coins from an image and
measures them, using three techniques from CSCD608 (Advanced Computer
Vision): **thresholding**, **region growing**, and **K-means clustering**.
Built for Question 4 ("Automated Image Segmentation and Object Measurement
System") of the CSCD608 final examination.

For each image, the pipeline segments coins with all three methods, draws
contours/bounding boxes/centroids, measures each coin (area, perimeter,
centroid, bounding box, enclosing circle), and evaluates each method
against hand-labelled ground truth using IoU / Precision / Recall / F1.

## Repository structure

```
.
├── dataset/                     # input images: coin_001.jpg ... coin_023.jpg
├── masks/                       # ground-truth binary masks (from label_masks.py)
├── labels.csv                   # per-image metadata: coin count, background, lighting, touching
├── label_masks.py               # tool to hand-annotate ground-truth masks
├── segmentation_pipeline.py     # runs all 3 segmentation methods + measurement
├── evaluate_segmentation.py     # scores predictions against ground truth
├── parameter_sweep.py           # sweeps K (K-means) and threshold (region growing)
├── requirements.txt
└── results/                     # generated by the scripts above (see "Outputs")
```

## Setup

Requires Python 3.9+.

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Running the project

Run the scripts **in this order** from the repository root (each one reads
files produced by the step before it):

### 1. Label ground truth (already done for this submission)

```bash
python label_masks.py
```

Opens each image in `dataset/` (a preselected subset of 8 — see
`SELECTED` in the script) in a matplotlib window. Left-click around a
coin's edge, press **Enter** to close that coin's outline, right-click to
undo the last point, and close the window when every coin in the image is
outlined. Saves one binary mask per image to `masks/`.

> Skip this step if `masks/` already contains your ground-truth masks.

### 2. Run the segmentation pipeline

```bash
python segmentation_pipeline.py
```

Segments every image in `dataset/` with all three methods, measures every
detected coin, and writes:

- `results/masks/<method>/coin_XXX_mask.png` — binary prediction masks
- `results/viz/<method>/coin_XXX_viz.png` — contours + bounding boxes + numbered coins
- `results/segmentation_results.csv` — per-image/method count, area, perimeter, processing time

### 3. Evaluate against ground truth

```bash
python evaluate_segmentation.py
```

Requires `masks/` (step 1) and `results/masks/` (step 2). Computes
IoU/Precision/Recall/F1 per labelled image and method, breaks results
down by lighting/background/touching (via `labels.csv`), runs a synthetic
noise + dim-illumination robustness test, and builds the required
method-comparison table. Writes:

- `results/eval_per_image.csv`
- `results/eval_by_condition.csv`
- `results/sensitivity_results.csv`
- `results/comparison_table.csv`
- `results/plots/*.png` — bar charts (IoU/precision/recall/F1 by method, by condition, processing time, noise/illumination sensitivity)

### 4. Parameter sweeps

```bash
python parameter_sweep.py
```

Requires `masks/` (step 1). Sweeps the region-growing similarity
threshold and K-means' K, scoring each value against ground truth. Writes:

- `results/sweep_region_growing_threshold.csv` + `results/plots/sweep_region_growing_threshold.png`
- `results/sweep_kmeans_k.csv` + `results/plots/sweep_kmeans_k.png`
- `results/plots/sweep_kmeans_k_qualitative_<image>.png` — visual comparison across K values

## Configuration

A few constants near the top of each script control behaviour and can be
edited directly:

| Script | Constant | Default | Meaning |
|---|---|---|---|
| `segmentation_pipeline.py` | `MIN_OBJECT_AREA` | `300` | minimum contour area (px²) to count as a coin, not noise |
| `segmentation_pipeline.py` | `KMEANS_K` | `3` | default number of K-means clusters |
| `segmentation_pipeline.py` | `REGION_GROW_THRESH` | `12` | default region-growing intensity similarity threshold |
| `parameter_sweep.py` | `KMEANS_K_VALUES` | `[2,3,4,5,6]` | K values swept |
| `parameter_sweep.py` | `REGION_GROW_THRESHOLDS` | `[5,10,15,20,25,30]` | thresholds swept |

## Notes

- All three segmentation methods are implemented from OpenCV primitives
  (Otsu thresholding, a hand-rolled flood-fill for region growing,
  `cv2.kmeans`) rather than high-level pre-trained detectors, per the
  assignment's instructions.
- The noise/illumination sensitivity test in `evaluate_segmentation.py`
  perturbs the labelled images synthetically (Gaussian noise, darkening)
  rather than relying on separately captured noisy/dim photos, so that a
  single variable is isolated in a controlled way.
